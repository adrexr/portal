# Clara Portal — demo

Demo local de portal de resultados y seguimiento. Solo muestra documentos ficticios y disponibilidad administrativa; no contiene resultados clínicos, diagnósticos, recetas reales ni datos personales.

Ejecuta `python main.py` y abre `http://127.0.0.1:8002`. Código de demostración: `DEMO-4821`.

Una implementación real requiere autenticación, sesiones seguras, TLS, cifrado, auditoría, controles por rol y revisión legal de privacidad sanitaria.
